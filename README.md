# Idea Map

Личная визуальная карта идей с кластерами и связями между темами.

## Что умеет
- идеи с заметками, тегами и визуальным референсом;
- автоматические связи между идеями из разных кластеров по общим тегам;
- ручные связи: «похоже на», «развивает», «можно объединить», «визуальный референс», «механика»;
- режимы «Карта» и «Карточки»;
- поиск и фильтрация;
- хранение данных в Supabase;
- доступ к данным только после авторизации, с RLS по пользователю.

## Backend
Проект использует Supabase project `family-budget`, но хранит данные в отдельных таблицах:
- `public.idea_map_ideas`
- `public.idea_map_links`

Существующие таблицы семейного бюджета не используются приложением.

## Deploy
Статика публикуется через GitHub Pages workflow из корня репозитория.
